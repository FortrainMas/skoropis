# Журнал экспериментов

Одна строка на эксперимент. Подробности — в файле эксперимента, исходные цифры — в
`runs/<прогон>/`. Как считаются метрики, описано в [validation.md](../validation.md).

CER указан в режиме `exact`, в процентах, на тестовой части.

## Как добавить эксперимент

1. Прогнать модель: `uv run diploma eval ... --name <прогон>`. Результаты лягут в
   `runs/<прогон>/`.
2. Построить графики: `uv run python scripts/report_figures.py run <прогон> --prefix E00N`.
3. Завести `E00N-<коротко>.md`: зачем запускали, модель и версия весов, данные, точная
   команда, таблица метрик, графики с пояснениями, разбор ошибок, выводы.
4. Добавить строку в таблицу выше.
5. Пересобрать PDF: `uv run python scripts/build_report.py`.
